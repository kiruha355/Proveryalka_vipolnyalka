## Порядок показа

1. Открыть «Нарушение v1»: требования, модель и конкретная трасса.
2. В чате показать настоящий уточняющий вопрос и адресный ответ.
3. Показать явную правку, затем «Исправленная v2» и результаты тех же свойств.
4. Открыть «Файлы и тесты»: rules.py, исходная модель, связь с требованиями, результаты pytest, ZIP.

Данные сохранены в рабочей SQLite стенда 5300. Это новые реальные GPT→TLC→codegen→Docker прогоны, не fixtures. Менять код приложения или перезапускать backend не потребовалось. Отсутствовавший pinned sandbox image восстановлен штатной сборкой без перезапуска Docker и изменения лимитов. Снимки T3 снова завершались timeout; новые PNG не заявлены. Код сгенерированных проектов в этой приёмке не доказывался для произвольной внешней реализации: pytest проверяет соответствие заданным моделям.
