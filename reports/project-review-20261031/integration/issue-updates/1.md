## Задача
Подготовить единый формат модели поведения и результата проверки для использования всеми компонентами приложения.

## Содержание
- [x] Реализовать Pydantic-схемы переменных enum/boolean/integer с конечными областями, начального состояния, переходов name/guard/effects и свойств.
- [x] Определить ограниченный DSL: операции, типы аргументов, одновременные присваивания и сохранение неизменённых переменных; запретить произвольный код в выражениях.
- [x] Предусмотреть invariant, forbidden_state, reachable, deadlock_free и ссылки source_refs на исходные требования.
- [x] Описать все шесть статусов VerificationResult, статистику, диагностические ошибки, состояния и имена переходов контрпримера, related_requirements.
- [x] Согласовать, как обозначается ожидаемое завершение процесса при проверке тупиков; не вводить исключения молча.
- [x] Добавить JSON Schema, документацию полей, два JSON-примера заявки и тесты сериализации, структуры и строгой типизации boolean/integer.

## Зависимости
Можно начинать независимо; формат данных согласуется в рамках общего контракта.
