# Архитектура Проверялки

`explain.html` — непрерывный документ с оглавлением, семью встроенными SVG и управлением масштабом. `diagrams/` содержит эти же схемы отдельными файлами; `diagrams.zip` — комплект для вставки в презентацию. `build.py` воспроизводит HTML, SVG и ZIP без дополнительных зависимостей.

Состав: компоненты и участники; путь описания и проверки; устройство ядра; отношения SQLite; генератор и Docker; документы/изображения/репозитории/MCP; native launcher и CI.

Зоны ответственности взяты из свежего чтения GitHub issues, архитектурные связи — из исходников и integration contracts. База основной цепочки — опубликованный PR66 `393ac0e`; последующие исправления основного E2E и файлового диалога выполняются отдельно. PR67/68/69 передали модули и wiring patches, а не автоматически подключённые общие routers. Их пунктирные соединения показаны соответственно. Изображения дают typed extraction; автоматический image-to-BehavioralModel путь не заявлен. Delivery PR70 использует существующий create_app.

Проверка: каждый из семи SVG просмотрен через native html_preview; тексты в блоках проверены по геометрии и визуально. Исправлены посимвольная раскладка ошибочно переданной строки, пересечение подписи с блоком файлов и длинные подписи. SVG XML, уникальные ID/якоря, целостность ZIP и синтаксис JS — PASS. Полный HTML проверен при 1144 px и 390 px, light/dark; узкие схемы сохраняют читаемый размер и горизонтальную прокрутку. Это проверка документа, не повторный E2E приложения.
