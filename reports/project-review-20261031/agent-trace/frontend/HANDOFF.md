# Ход работы агента

Реализовано в `frontend/src`: сворачиваемый журнал «Ход работы» в блоке ответа. Во время запуска виден один фактический этап; раскрытие показывает сохранённые события и их серверное время. Длительность появляется только при известных серверных начале и конце. Внутренние рассуждения, prompt и произвольный payload события не выводятся.

Источник истории — `GET /api/sessions/{session_id}/agent-runs?limit=50&before=...`. Поддержаны загрузка предыдущей страницы, ошибка чтения с повтором, обнаружение запущенного процесса после открытия нового браузера, слияние HTTP snapshot и SSE по `(run_id,event_id)`, обновление снимка после terminal event. Polling не добавлен.

История связана по `input_entry_id`/`reply_entry_id`. Неудачная попытка остаётся после своего входного сообщения; успешный повтор связан со своим ответом. Исходный текст не используется для восстановления связей исторических запусков. Данные записанных demo fixtures не менялись.

Validation `passed` и `failed` показаны отдельно. `model_proposed.changed:false` отображается как использование существующей версии. Ошибка, отмена, потеря связи и повтор соединения имеют разные статусы. Для старой истории без сохранённых этапов показано ограничение данных; этапы и время не восстанавливаются предположениями.
