# Подписи переходов и петли

31.10.2026. Исправление по пользовательской аннотации `10ecdc2b-23d7-4ec5-8e85-4b6490fbb5aa-41882a88-7b20-4f63-a60f-66a0a2397d0f.png`.

Причины: несколько selfloops одного узла собирались в одну кривую с общей областью подписей; подпись петли центрировалась на вершине собственной кривой. `opacity: 0.5` у неактивной подписи делал прозрачным и её фон, поэтому стрелки просвечивали через текст.

Изменения:

- Каждая петля получила отдельную кривую. Стабильная сортировка по исходному projection edge ID распределяет петли по верхней и нижней сторонам, затем по дополнительным дорожкам. Фильтр условных переходов и текущий шаг трассы не переставляют оставшиеся дорожки.
- Текст петли расположен за её вершиной с зазором 8px, сверху либо снизу. Расстояния между узлами и размер полотна не увеличены.
- Ширина подписей ограничена 176px, а для прямой стрелки — доступным промежутком между узлами с полями. Длинные имена и номера шагов переносятся; текст и доступные имена сохранены.
- Фон подписи и кнопки непрозрачен. Неактивная подпись меняет цвет текста без прозрачности всего элемента. Сохраняются отдельные состояния выбранного перехода, текущего шага и нарушения.
- `EdgeChip.edgeId` остаётся исходным идентификатором проекции. Разделение кривых не меняет привязку выбора, трассы и инспектора.
