# Область диаграммы

Дата: 31.10.2026. Изменения в рабочем дереве `work/project-integration-20261031`.

## Изменения

- В обычном режиме удалены верхняя полоса и верхняя кнопка разворачивания. Единственная кнопка «Развернуть диаграмму» находится справа внизу, в блоке масштаба. Отдельная кнопка «Вписать граф» удалена; сброс масштаба до 100% остаётся на числовом индикаторе.
- В развёрнутом режиме есть один крестик закрытия в заголовке. Остаются тот же экземпляр React Flow, выбор перехода и шаг трассы. Смена размера режима по-прежнему меняет `fitToken` и вызывает автоматическое вписывание.
- Перед открытием запоминается элемент для возврата фокуса. После Escape или крестика фокус возвращается на нижнюю кнопку. Сохраняются ограничение Tab внутри диалога, `inert` у фоновых элементов и восстановление `body.style.overflow`.
- Только вкладка диаграммы использует ограниченную по высоте flex-область: `workspace__body--diagram` → `workspace__view--diagram` → `pv-workspace` → `pv-stage-area`. Минимальная высота графа 360px удалена, граф занимает остаток доступной высоты.
- Инспекторы и длинные предупреждения прокручиваются внутри своих ограниченных областей. Заголовок рабочей области и управление графом не участвуют в общей прокрутке. Вкладки текста сохраняют прокрутку `workspace__body`, класс `workspace__view--files` и файловые разделители не изменены.
